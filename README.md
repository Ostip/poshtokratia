# Залізна Зміна

Сайт з історіями, листами та мемами.

## Хто що бачить

- **Публічно (бачать усі відвідувачі):** історії (картки), листи, меми.
- **Приватно (бачите лише ви):** список зареєстрованих людей (ім'я, email, дата
  реєстрації). Ці дані ніколи не потрапляють у публічний `/api/state` і не
  видно у вихідному коді сторінки — доступ лише через `/admin` за паролем.

## Запуск локально

```bash
npm install
npm start
```

Відкрийте http://localhost:3000/.

## Перегляд зареєстрованих людей

1. Задайте пароль адміністратора через змінну середовища `ADMIN_PASSWORD`
   (обов'язково перед деплоєм — інакше буде використано слабкий пароль за
   замовчуванням).
2. Відкрийте `/admin` на сайті та введіть цей пароль.

Дані зберігаються у файлі `data.json` на сервері (у полі `users`), не в
браузері й не у фронтенд-коді, тож звичайні відвідувачі до них доступу не
мають.

## Деплой на Render

1. Завантажте проект на GitHub.
2. У Render створіть **New Web Service** з репозиторію (використає
   `render.yaml`: `npm install` → `npm start`).
3. У розділі **Environment** додайте змінну `ADMIN_PASSWORD` зі своїм
   надійним паролем.
4. Після деплою сайт буде доступний за URL від Render, адмінка — за
   `https://ваш-сайт.onrender.com/admin`.

## Важливо про збереження даних

`data.json` зберігається на диску сервера. На безкоштовному плані Render
диск не persist між релізами/рестартами контейнера — якщо потрібне надійне
довгострокове зберігання (особливо для списку користувачів), варто
підключити базу даних (наприклад, Render Postgres чи Supabase) замість
локального файлу. Скажіть, якщо хочете, щоб я це налаштував.
