# Залізна Зміна

Сайт з історіями, листами та мемами.

## Хто що бачить

- **Публічно (бачать усі відвідувачі):** історії (картки), листи, меми.
- **Приватно (бачите лише ви):** список зареєстрованих людей (ім'я, email,
  дата реєстрації) — доступ лише через `/admin` за паролем.

## Де зберігаються дані

Сайт вміє працювати у двох режимах:

- **З Postgres (рекомендовано для продакшену):** якщо задана змінна
  середовища `DATABASE_URL`, усі дані (користувачі, історії, листи, меми)
  зберігаються в базі даних PostgreSQL. Таблиці створюються автоматично при
  першому запуску сервера. Дані переживають рестарти й релізи сервісу.
- **Локальний файл (для розробки без бази):** якщо `DATABASE_URL` не
  задано, сервер зберігає все у файлі `data.json` поруч із кодом — зручно
  для локального тестування, але на безкоштовному плані Render такий файл
  може губитись при рестарті контейнера.

## Підключення Postgres на Render

1. У Render dashboard натисніть **New +** → **PostgreSQL**. Оберіть план
   **Free**, той самий регіон, що й ваш веб-сервіс (наприклад, Oregon).
   Дайте назву, наприклад `zalizna-zmina-db`, і натисніть **Create Database**.
2. Зачекайте, поки база створиться (1-2 хвилини). Відкрийте її сторінку —
   там буде поле **Internal Database URL** (якщо база і сервіс в одному
   регіоні — використовуйте саме його, він швидший і безкоштовний за
   трафік).
3. Скопіюйте це значення.
4. Перейдіть у ваш веб-сервіс → **Environment** → **Add Environment
   Variable**. Ключ: `DATABASE_URL`. Значення: вставте скопійований
   Internal Database URL.
5. Збережіть — Render автоматично передеплоїть сервіс. При старті сервер
   сам створить потрібні таблиці (`users`, `cards`, `letters`, `memes`).
6. Перевірте `/api/health` — має показати `"storage":"postgres"`.

### Якщо в data.json вже були реальні дані

Якщо на сервері вже назбиралися реальні картки/листи/меми/користувачі у
старому `data.json` і ви не хочете їх втратити:

1. Відкрийте **Shell** вашого веб-сервісу в Render (вкладка "Shell").
2. Виконайте: `npm run migrate-data`
3. Скрипт перенесе все з `data.json` у Postgres (без дублювання, якщо
   запустити двічі — записи з однаковим id просто пропускаються).

## Запуск локально

```bash
npm install
npm start
```

Без `DATABASE_URL` в середовищі сервер автоматично використає локальний
`data.json`. Відкрийте http://localhost:3000/.

## Перегляд зареєстрованих людей

1. Задайте пароль адміністратора через змінну середовища `ADMIN_PASSWORD`.
2. Відкрийте `/admin` на сайті та введіть цей пароль.

## Деплой на Render

1. Завантажте проект на GitHub.
2. У Render створіть **New Web Service** з репозиторію (використає
   `render.yaml`: `npm install` → `npm start`).
3. Додайте змінні середовища `ADMIN_PASSWORD` і (рекомендовано) `DATABASE_URL`
   (див. розділ вище).
4. Після деплою сайт буде доступний за URL від Render, адмінка — за
   `/admin`.
